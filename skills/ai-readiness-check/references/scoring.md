# Scoring bands and priority moves

Total is the sum of Questions 1 to 4, each scored 0 to 3. Question 5 is
not scored. It is used for routing only.

## 0 to 3: Not Ready Yet

Foundation work first: assign an owner, inventory AI use, set a basic
policy. Strong handoff. Offer the $99 assessment as the starting
roadmap.

Priority moves by low answer:

- Question 1 low: Name one person to own AI decisions this week, and
  write down in one page where AI should and should not be used.
- Question 2 low: Pick the one set of records AI would need first and
  get it into one place before trying any tool.
- Question 3 low: Write a one-page policy for tools like ChatGPT and
  Claude, and ask the team which AI tools they already use.
- Question 4 low: Pick the single most repeated weekly task and time
  it for one week, so the first use case has a number behind it.

## 4 to 6: Getting Started

Some use, little structure. Focus on one use case, data cleanup, and
guardrails. Strong handoff.

Priority moves by low answer:

- Question 1 low: Put the informal owner in writing and set a monthly
  check-in on AI use.
- Question 2 low: Clean up the data for the one use case that matters
  most, and leave the rest for later.
- Question 3 low: Turn the rough policy into a written one and confirm
  the team knows it.
- Question 4 low: Give the team one short training session on the one
  tool tied to the first use case.

## 7 to 9: Building

Real momentum with gaps in governance or data. Focus on formalizing
what works. Handoff framed as governance and scale.

Priority moves by low answer:

- Question 1 low: Move the rough plan into a written plan with named
  owners for each use case.
- Question 2 low: Close the data gaps for the use cases already
  running, starting with the one that touches clients.
- Question 3 low: Audit which AI tools are actually in use and bring
  the stragglers under the policy.
- Question 4 low: Train the rest of the team on the use cases that
  already work, so the win spreads past one person.

## 10 to 12: Ready to Scale

Structured and owned. Focus on oversight, measurement, and risk as use
expands. Handoff framed as independent review.

Priority moves by low answer:

- Question 1 low: Review the plan quarterly against what the team
  actually does, and update it.
- Question 2 low: Set a simple data quality check for any new source
  before it feeds an AI tool.
- Question 3 low: Review the policy against new tools every quarter
  and retire tools no one owns.
- Question 4 low: Measure time saved on the live use cases and use
  the number to pick the next one.
